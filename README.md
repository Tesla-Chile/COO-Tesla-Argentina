# Tesla Argentina — Costo de Propiedad Total

Copia de la aplicación de Chile, adaptada a pesos argentinos (ARS).
Abrir `index.html` en un navegador. No requiere instalación.

- Combustible: $2.700 ARS/L inicial; rango de 0 a 5.000.
- Electricidad: $200 ARS/kWh inicial; rango de 0 a 400.
- Costo por mantención: hasta $3.000.000 ARS.
- Patente: valores anuales, editables para ambos vehículos.
- Seguros: valores mensuales, de 0 a $1.000.000 ARS; ambos comienzan en 0.

Se conservan el diseño, modelos y fórmulas de la aplicación original.
Restablecer recupera los valores iniciales de esta versión argentina.
